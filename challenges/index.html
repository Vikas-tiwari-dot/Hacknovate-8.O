Track 01 · Coding Task Factory

Make coding tasks AI cannot shortcut.

Using a supplied working software repository, build one reusable strategy for generating realistic feature-development tasks suitable for evaluating AI coding systems. Focus on automated scenario design, test synthesis and repeatability across varied feature footprints.

The big question: How can we automatically create realistic software-development tasks that are clear, solvable and reliably testable?

pallets/click ↗colinhacks/zod ↗open-source-parsers/jsoncpp ↗

What you’ll build

  • Clear, achievable requirements for a new feature
  • A reference implementation that runs in the repo’s stack
  • Feature tests plus regression checks for existing code
  • Packages tagged to their starting repo version

How to stand out

  • Prove each implementation meets its requirements
  • Show tests catch missing or incorrect behaviour
  • Vary behaviour, rules or interactions, not just names
  • Meaningful variation beats a high task count

What you’ll submit

  • A reusable task-generation pipeline
  • Sample task packages
  • Validation evidence: tests, runs and results
  • A live demo generating and validating a package

Example

A shopping-cart app gets a generated task to add discount codes with eligibility rules and spending thresholds, plus tests that prove it works.

Great fit if you enjoy

Extending codebasesModel APIsTestable requirementsTesting & debuggingAI evaluation

Code-generation or AI-evaluation experience helps, but strong programming fundamentals matter most.

Track 02 · Visual Task Factory

Put vision and GUI models to the test.

Build an automated visual evaluation engine that crafts multimodal test suites challenging frontier vision and GUI-agent models. Generate diverse visual stimuli, UI interactions, edge-case chart artifacts and pixel-precise verification suites.

The big question: How can we systematically stress-test multimodal models with verifiable ground-truth visual tasks?

What you’ll build

  • Automated visual task generation pipeline
  • Pixel-precise or layout-level verification harnesses
  • Multimodal ground-truth test data suites
  • Reproducible test environment configurations

How to stand out

  • High variance across layout complexities and visual domains
  • Robust automated grading resistant to superficial visual cues
  • Measurable failure-mode discoveries on frontier vision LLMs
  • Clean visual benchmark dashboards and documentation

What you’ll submit

  • End-to-end visual task factory codebase
  • Validated test packages and visual dataset splits
  • Empirical benchmark results against frontier models
  • Demonstration video and execution pipeline guide

Example

Synthesize dynamic dashboard infographics with intricate chart alignments and generate automated visual QA queries that test layout reasoning.

Great fit if you enjoy

Computer visionMultimodal LLMsSynthetic visual dataVisual testingBenchmark design

Vision and multimodal experience is a plus, but structured problem-solving and clean engineering are paramount.
